2D GAME ICON PACK
=================

A premium collection of 192 hand-painted style 2D game icons, designed for
indie games, mobile games, PC games, RPGs, roguelikes, adventure games,
strategy games, survival games, fantasy games, and general-purpose 2D games.

CONTENTS
--------
12 categories x 16 icons each = 192 icons:

  Melee_Weapons/   Swords, axes, hammers, maces, daggers, spears...
  Ranged_Weapons/  Bows, crossbows, throwing knives, staves, wands...
  Armor/           Helmets, chestplates, shields...
  Potions/         Health, mana, stamina, resistance, poison, antidote...
  Magic/           Spell orbs, runes, crystals, scrolls, tomes...
  Resources/       Gems, ores, crystals, coal...
  Food/            Apple, bread, cheese, meat, meals...
  Tools/           Pickaxe, lantern, torch, compass, repair kit...
  Treasure/        Coins, chests, ingots, crafting materials...
  Quest_Items/     Keys, maps, scrolls, relics, insignias...
  Artifacts/       Crowns, rings, masks, relics...
  Utility/         Target, health/energy symbols, rewards, chests...

TECHNICAL DETAILS
-----------------
- Format: PNG with true transparency (RGBA)
- Size: 400 x 400 px per icon (high resolution, downscales cleanly to
  256, 128, 64 and 32 px)
- Art style: cohesive stylized hand-painted look, consistent lighting
  (upper-left light source), one clearly readable object per icon
- No text, watermarks or backgrounds in the icon files

SUGGESTED USE
-------------
Import the PNG files directly into your 2D game engine:

- Godot: drag into your project, use as TextureRect / Sprite2D textures,
  or slice into an AtlasTexture for inventory grids.
- Unity: import as Sprites, set Mesh Type to Tight for clean edges.
- Unreal Engine / GameMaker / Construct: import as 2D textures/sprites.

The icons work at any UI scale and are ideal for inventories, hotbars,
shop menus, loot popups, crafting screens, and HUD elements.
